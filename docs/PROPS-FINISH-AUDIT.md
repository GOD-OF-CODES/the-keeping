## Ranking formula

score = screen time (1 glance … 5 handled/read or in a cutscene) × closeness (1 = > 4 m, 2 = 2–4 m, 3 = 0.4–1.5 m)
× story weight (1 dressing, 2 story-referenced in `src/story`/`src/cutscenes`, 3 player action: `take_*`, `read_*`,
`pull_bell`). Max 45.

## Recommended build order (biggest visible gain per hour)

1. **Quick wins (spec/one-liners, < 1 h):** hog_cleaver → `steel_cleaver`; sewing_shears → polished steel spec; claw_hammer head → steel, handle → hickory spec; `dust`/`dustOnTop` 0.3–0.6 on all furniture/metal specs (X6); re-enable guest_book cover curl.
2. **X2 normals + bevels in `kit.py`** (weighted normals, bevel all boxes, lathe/tube segment floors) → re-export every prop; then delete the `toCreasedNormals` band-aid in `src/world/opening.ts`. Fixes faceting on rows 7, 9, 10, 16, 22, 25–27 at once.
3. **X1 vertex masks** (curvature/AO/handled/dust → `COLOR_0`) + one shared runtime mask path in `bind.ts`. Biggest single realism gain for every prop at 0.4–1.5 m.
4. **Hero handheld/readable pass** (rows 1–9): letter, locket chain links, ledger/guest-book page blocks, ticket, shears, hammer, jerry can, bell pull.
5. **X3 texel density** for wood_furniture_dark / cast_iron / wood_raw_plank (hero 1024, smaller tileMetres).
6. **X4 hardware kit** (hinges, screws, escutcheons, reveals) across furniture rows 16–26.
7. **X6 grime decals** (wax spill, water ring, soot, rust streak) placed at candles, lamps, fixings.
